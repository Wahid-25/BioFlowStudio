# BioFlow Studio

BioFlow Studio is a C++ desktop bioinformatics application based on object-oriented programming.

## Main Workspaces

### Phylogenetic Analysis

This workspace will process FASTA sequences, perform pairwise alignment, calculate distance matrices, identify conserved regions, and construct phylogenetic trees.

### Gene Expression Analysis

This workspace will process gene-expression datasets, perform quality control, normalization, correlation analysis, PCA, differential-expression analysis, and candidate biomarker ranking.

## Main Technologies

- C++
- CMake
- Qt
- SQLite
- Eigen
- Git and GitHub
- Jupyter Notebook for algorithm verification
